# Upstream #4402: Private CA für S3-Verbindungen gezielt vertrauen

## Aufarbeitung: Private CA für S3-Verbindungen gezielt vertrauen

**Bereich:** S3 / TLS · **Priorität:** P2 · **Bewertung:** Erweiterung

**Prüfgrundlage:** statische Prüfung von Meldung, abrufbarer Diskussion und Code bei `30335d80866ff3391d899cf4ccb599b696f47b7e`. Keine Laufzeitreproduktion oder Fehlerbehebung in dieser Aufarbeitung.

### Problem und Abgrenzung

Die Zertifikatskette eines internen S3-Endpunkts ist im Coolify-Container nicht vertrauenswürdig, obwohl sie auf dem Host installiert wurde. Aktuell gibt es eine Option zum Überspringen der TLS-Prüfung; diese ersetzt keine saubere eigene CA-Vertrauensstellung.

### Reproduktion / Prüfszenario

1. Internen S3-Testendpunkt mit privater CA bereitstellen.
2. Root-CA nur auf dem Host installieren und die S3-Verbindung aus Coolify prüfen.
3. Danach dieselbe CA kontrolliert in den tatsächlich verwendeten Client-/Upload-Container geben und erneut prüfen.

### Befunde

- Die Fehlermeldung ist cURL error 60: unable to get local issuer certificate.
- Kommentar 2516570263 grenzt den fehlenden Container-Truststore ein.
- S3Storage::httpClientOptions und minioClientEnvOptions berücksichtigen aktuell skip_tls_verification, aber kein hier sichtbares pro-Storage-CA-Feld.

### Umsetzungsschritte

- [ ] Einen expliziten CA-Bundle-Pfad oder eine verwaltete CA-Zuordnung für S3-Clients entwerfen.
- [ ] PHP-Client und Upload-/Download-Hilfscontainer auf dasselbe verifizierte CA-Material abstimmen.
- [ ] Host-Truststores nicht ungeprüft vollständig übernehmen.

### Abnahmekriterien und Regressionstests

- [ ] Privater Endpunkt mit korrekter CA funktioniert bei aktiver Zertifikatsprüfung.
- [ ] Falsche CA, falscher Hostname und abgelaufenes Zertifikat werden abgewiesen.
- [ ] Öffentliche S3-Anbieter funktionieren unverändert.

### Offene Fragen und Risiken

- Container und Host können unterschiedliche Truststore-Formate verwenden.
- Die Aufnahme eines Serverzertifikats ist nicht identisch mit Vertrauen in die ausstellende CA.
